# Notes for agents

These rules come from errors that were made and fixed in this repository more
than once. Read them before changing the rulebook, the adventure, the
character sheets or the site.

## Sources of truth
- **Rulebook:** `manual.tex` and `manual-<lang>.tex`.
- **Adventure:** `adventure/hollow-hearth-<lang>.tex`.
  - Every adventure file carries the adventure's slug: sources `adventure/<slug>-<lang>.tex`, print images `assets/<slug>/`, web images `docs/assets/<slug>/`, web pages `docs/<lang>/adventures/<content_id>/` (the `content_id` of `docs/_adventures/`), PDFs `docs/downloads/<slug>-<lang>.pdf` (linked from `pdf_path` in `docs/_adventures/`). Never use generic names such as `adventure-<lang>`: a second adventure would collide with them.
  - `docs/<lang>/adventures/<content_id>/read/*.html` are generated by `scripts/build-adventure-html.py`. Never edit them by hand: edit the `.tex`, then regenerate.
  - Never regenerate them from any other copy of the sources. A web edition aligned to an uncorrected print copy has already undone a full round of fixes.
- **Prologue:** `adventure/path-of-debts-<lang>.tex` ("The Path of Debts", a story that leads into the adventure; English is the reference). It belongs to the adventure: its entry in `docs/_adventures/` lists it under `prologue`, and its web pages are `docs/<lang>/adventures/the-bell-of-hollow-hearth/prologue/01-04.html` (the story in three parts, then "For the Narrator"), generated by `scripts/build-prologue-html.py`. Never edit them by hand.
  - "For the Narrator" reveals the adventure's secrets: it starts on its own page in the PDF, opens with a warning, and stays out of the players' previous/next chain on the web.
  - Nim is a woman and Mara a man, as on the pregenerated sheets; the dice in the "At the table" boxes, the TNs and the outcomes must be identical in every language.
- **English is the reference:** every translation mirrors the English structure. That means the same section levels, `rpgnote` stat boxes, `quote` boxes, figures, table rows (same order) and manual page references.
- **Authorial cuts:** when the English source drops or shortens a passage, the translations follow. Do not re-add text English no longer has.

## Game rules the adventure must respect (verify in `manual.tex`)
- **Opposed rolls:** both sides roll and the higher wins. Never also give a fixed TN.
- **Exertion:** +1d6 is declared before the roll; the Fatigue Wound is taken **after** the roll.
- **Enemy stat lines** follow the rulebook's enemy format and start with the TN (Strength/Dexterity).
- **HP states:** ≤ 2 HP is −1 tier; ≤ 1 HP is −2 tiers.
- **Examples are not limits:** the rulebook gives examples, not exhaustive lists, for weapons, armour and enemies. An invented item or value is fine when its numbers are stated. Do not report it as an error.

## Manual page references
- **Numbering:** cite the **printed** page number (the rulebook's own table of contents), not the PDF page index.
- **Per language:** pagination differs between languages (for example, German chapters start one to two pages later than English from Combat onward). Never reuse another language's numbers; take each number from that language's `docs/downloads/rulebook-<lang>.pdf`.
- **Re-check after edits:** any edit to a manual can move pages. A small change once grew the Spanish rulebook from 16 to 17 pages.

## Terminology
- **Source of terms:** use the published terms of each language, from `manual-<lang>.tex` and `character-sheets/locales/<lang>.tex`.
- **Mistakes that came back before:**
  - IT: Combattente (not Guerriero), Addosso, Intimidire, Tattiche, Lama del Sale.
  - FR: Aide / Aide compétente (not Entraide), Œil du néant, Acrobatie, Espèces.
  - DE: Merkmal, Fern, Erzähler, Einschüchtern, Heilkunde, Vergleichswurf.
  - ES: Contacto / Cerca / A distancia / Lejos, Narrador.
  - UK: Поруч, протилежні кидки, щабель.
- **Fire timing:** the brazier fire spreads over "two scenes", not "two narrative exchanges". Every translation got this wrong once.

## PDFs and toolchain
- **Pinned container only:** publishable PDFs come only from the pinned container. Its image, `at-the-last-throw-tex:tl2024`, is defined by the `Dockerfile` at the repository root (TeX Live 2024, FreeSerif, poppler-utils, ImageMagick 7, all pinned). Every `make docker*` target builds it on first use, which takes about two minutes and needs about 2.5 GB. Only Docker and GNU Make are needed on the host.
- **Make targets:**

  | Target | What it does |
  |---|---|
  | `make docker` | rulebooks into `build/` |
  | `make docker-adventure` | print JPEGs from the PNG originals, then the adventure PDFs into `docs/downloads/` (`SLUG=hollow-hearth`) |
  | `make docker-sheets` | the 30 character sheets in `character-sheets/`, with all their checks; copy the ones you mean to publish to `docs/downloads/` |
  | `make site` | the Jekyll site into `build/site/` in the official `ruby:3.3` image (GitHub Pages gems from `docs/Gemfile.lock`, cached in the `jekyll-gems` volume), then the link check |
  | `make site-serve` | the same site with live reload on port 4000 (on a Chromebook, open `http://penguin.linux.test:4000/`) |
  | `make page-counts` | the page count of every PDF in `docs/downloads/` against `REF` (default `origin/main`) |
  | `make docker-shell` | a shell inside the pinned container |

  The scripts behind the targets (`scripts/build-adventure-*.sh`, `character-sheets/build.sh`) can also be run with `docker run --rm -u "$(id -u):$(id -g)" -v "$PWD":/work -w /work at-the-last-throw-tex:tl2024 <script>`.
- **Same content, new bytes:** a rebuild embeds new dates, so an unchanged PDF still shows as modified. Commit a rebuilt PDF only when its content changed: compare text and pixels with the committed version, and otherwise restore it with `git checkout`.
- **Local TeX Live:** a local TeX Live renders differently, pixel by pixel. Use it only as a syntax check and never commit its PDFs.
- **Adventure images:** the full-resolution PNG originals in `assets/hollow-hearth/*.png` are the source. Never derive anything from the low-resolution web `.webp` files.
  - The print sources include JPEG copies of the interior illustrations (`assets/hollow-hearth/*.jpg`), made from the PNG originals by `scripts/build-adventure-print-art.sh` inside the pinned container. Embedded as PNG they made each adventure PDF about 36 MB.
  - After changing a PNG original, rerun that script and commit the new `.jpg`. Never edit a `.jpg` by hand.
  - The cover overlays (`*-overlay.png`) stay PNG: they need their transparency on the parchment cover.
  - The same script makes `assets/engraved-*-background.jpg` (quality 95) from the shared cover PNGs; the adventure covers use the JPEGs, the rulebook still uses the PNGs.
  - The character-sheet artwork works the same way: `build.sh` makes `character-sheets/assets/character-background.jpg` (quality 95) from the PNG, the sheets embed the JPEG, and the collision test measures the PNG. Never edit the JPEG by hand.
- **Web edition of an adventure:** `scripts/build-adventure-html.py` needs pandoc and Pillow (not in the container); its committed output was made with pandoc 2.17.1.1. The `.webp` web images are made from the PNG originals.

## Character sheet
- **How the text is placed:** words are placed in millimetres over a raster artwork (`character-sheets/assets/character-background.png`). Measure the free space on the artwork before moving or adding text.
- **Fitting text:** use `\SheetFit` instead of per-language font-size branches.
- **Font limits:** IM Fell English has no bold and no Cyrillic; Cinzel Decorative has no Cyrillic.
- **Build checks:** `build.sh` fails on font substitutions and on any text pixel that touches an engraved line. Do not weaken these checks to get a pass.
- **Pregenerated sheets:** `hollow-hearth-pregens-<lang>.tex` fill the same template with the data in `pregens/hollow-hearth-<lang>.tex` (portraits in `assets/hollow-hearth/pregens/`); `build.sh` builds and checks each sheet.
  - Every build must follow the creation rules in `manual.tex`: 10 points, the class HP range, skills only in Attributes at Competent or better, weapon damage, armour access and Grimoire fields.
  - Each translation mirrors the English data file and takes its terms from that language's manual.
  - The notes are a play reminder, not the creation cost: the character's key rolls with the dice already worked out (Attribute + Skill tier, `\SheetUp`/`\SheetDown` arrows), Exertion, and any rule the character is most likely to get wrong. A Grimoire's Cost carries its unit (Fatigue). The weapon goes in its own `weapon` field, not among the skills.
  - Boxes above the maximum Hit Points are shaded, never crossed out: a cross reads as a wound.
  - `build.sh` builds one A4 PDF per character (`\PregenOnly` selects it). Publish them as `docs/downloads/<slug>-<character>-<lang>.pdf`.
  - Each character goes with its own adventure: list it under `pregenerated` in `docs/_adventures/<slug>-<lang>.md`, with a web portrait in `docs/assets/<slug>/pregens/` made from the PNG original. The overview, downloads and catalog pages read that list. Never put the sheets in a separate section or bundle them in a single file.

## Before claiming something is done
- **Every language, every file:** a claim about "all languages" or "no regressions" needs a check of all six languages and every affected file, never a sample. A page-count check of English alone once missed that the Spanish adventure had grown from 15 to 16 pages.
- **Page counts:** run `make page-counts` (and with `REF=<commit before your change>`). Explain every changed count in the pull request, and re-check the page references that cite a PDF that grew.
- **Rebuilt PDFs:** compare every language with the previous build, page by page (`pdftotext` per page and a pixel comparison with `pdftoppm` plus `compare`). Only the pages you meant to change may differ. A longer sentence once pushed two lines of the German adventure onto the next page.
- **Numbers derived from the rules** (sheet notes, examples): work them out with every rule that applies at that moment. A Grimoire's Cost is paid first, and the resulting HP state already penalises the roll: Elyra (4 HP) pays 2F for Wall of Flames, so she rolls at 2 HP, −1 tier.
- **Adventure text against published data:** a sentence about "the Mystic" or "the Fighter" must agree with the pregenerated characters. "The Mystic with 2 HP" contradicted Elyra's 4 HP.
- **TeX control words eat the following space:** write `\SheetUp\ against`, not `\SheetUp against`.
- **Site:** run the Jekyll build, then `python3 scripts/check-jekyll-site.py --built <site>`.
- **Adventure pages:** rerun `scripts/build-adventure-html.py` and `scripts/build-prologue-html.py`; the result must leave `git diff` on `docs/*/adventures/*/read/` and `docs/*/adventures/*/prologue/` empty.
- **Word counts:** `wc -w` miscounts Cyrillic text, so compare word counts with a Unicode-aware tokenizer.
- **Before pushing:** run `git fetch` and look for commits from other sessions on the branch. Read them and check that they do not conflict with yours, by file or by logic, before rebasing.
- **Pull request description:** edit it from its current version (`gh pr view --json body`), never from an old copy, so other sessions' additions survive. When the work is done, rewrite it from the current state: stale claims accumulate.
- **Publication:** GitHub Pages serves `main:/docs` at atthelastthrow.com. Anything merged into `main` is published at once.
