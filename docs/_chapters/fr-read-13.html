XIII · Chapitre

Guide du Narrateur

◆

Le Seuil de difficulté est votre outil principal. Le SD de base est 4. Augmentez-le pour les actions difficiles, réduisez-le pour les actions simples. Rien d’autre n’est nécessaire pour calibrer un défi.

L’Épuisement engendre l’aventure. Après l’échec d’une action Critique, le groupe ne peut pas simplement recommencer par la force : il doit trouver une autre voie. Cette contrainte encourage la créativité.

Chaque ennemi veut quelque chose. Un brigand veut de l’argent, pas nécessairement la mort. Un démon veut un pacte, pas une bagarre. Les motivations comptent davantage que les statistiques.

Demandez toujours « Comment fais-tu ? » La réponse détermine la Caractéristique utilisée et le SD.

Interprétez le degré de réussite. Un 6 face à SD 3 n’équivaut pas à un 4 face à SD 4. Les deux réussissent, mais le premier brillamment et le second de justesse. Jouez cette nuance.

Les Blessures de Fatigue sont un outil. Toute action extrême peut en coûter : soulever un rocher, courir des heures, résister à un poison. Elles ne concernent pas uniquement la magie.

La magie est une décision collective. Le Contrecoup d’un Grimoire peut affecter tout le monde. Avant un lancement risqué, laissez le groupe en discuter.

Les interactions sociales utilisent les mêmes règles. Persuader, mentir, intimider : lancez Savoir + la Compétence pertinente contre un SD. Aucun système distinct n’est nécessaire pour les conflits sociaux.
